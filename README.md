## Ingeniería

Antes de implementar, fijar el alcance de **arquitectura, compilación, pruebas unitarias e instrumentadas, cobertura, análisis estático, calidad de CI, seguridad, reproducibilidad, mutation testing, deuda técnica y evidencia de ejecución**.

Decisiones iniciales:
- Distinguir sitio corporativo de marketplace, consola Control y demás aplicaciones operativas.
- Reutilizar patrones comprobables, no fusionar proyectos completos sin revisión.
- Mantener contenido publicable separado del prototipo.
- Trabajar sobre ramas y PR para desarrollo posterior. No usar auto-merge.
- No configurar despliegue ni dominio hasta contar con requisitos y aprobación explícitos.
